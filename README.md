# ערכת איסוף של Sauce

זו ערכה קטנה שאוספת את מה שצריך כדי שנכין לך קרוסלות על המוצר שלך.
היא קוראת את הקוד של המוצר, שואלת אותך כמה שאלות קצרות, ומצלמת כמה מסכים.
בסוף נוצרת תיקייה אחת בשם `sauce-intake/`, ואותה שולחים לנו.

## בחר דרך אחת, לפי הכלי שיש לך

### דרך א: Claude Code

1. פתח טרמינל בתוך התיקייה של הפרויקט שלך.
2. הרץ `claude`.
3. הדבק את השורה הזאת ולחץ Enter:

```
Download https://raw.githubusercontent.com/oritauber-alt/sauce-intake/main/PROMPT.md with curl into a temp file, read that file, and follow it exactly.
```

אם הסוכן שלך לא מצליח לקרוא כתובת מהאינטרנט, אפשר גם כך:

1. שכפל את הריפו הזה לתיקייה שליד הפרויקט שלך (לא בתוכו):

```
git clone https://github.com/oritauber-alt/sauce-intake.git
```

2. בתוך התיקייה של הפרויקט שלך הרץ `claude` והדבק:

```
Read ../sauce-intake/PROMPT.md and follow it exactly.
```

### דרך ב: Cursor, Codex או כל סוכן קוד אחר

1. פתח את הפרויקט שלך בכלי.
2. העתק את כל התוכן של `PROMPT.md` והדבק אותו בצ'אט של הסוכן.

### דרך ג: אין לך סוכן קוד, רק צ'אט (כמו ChatGPT או Claude)

1. העתק את כל התוכן של `QUESTIONS.md` והדבק אותו בצ'אט.
2. ענה על השאלות אחת אחת. בסוף הצ'אט יחזיר לך קובץ בשם `customer.json`.
3. צור תיקייה בשם `sauce-intake/` ושמור בה את `customer.json`.
4. צלם מסכים לפי `SCREENSHOTS.md` ושים אותם בתיקייה `sauce-intake/screenshots/`.
5. אם יש לך קובץ לוגו, שים אותו בתיקייה `sauce-intake/brand/`.

## בסוף, בכל דרך

כווץ את התיקייה `sauce-intake/` לקובץ zip ושלח לנו (בוואטסאפ או בדרייב).
אחרי ששלחת, מחק את התיקייה מהמחשב. היא לא נכנסת לגיט שלך, והערכה לא נוגעת בקובץ `.gitignore` שלך.

## מה הערכה קוראת, מה לא, ומה יוצא מהמחשב שלך

קוראת: קבצי README ודוקים, עמודי שיווק ותמחור, קבצי טקסטים של הממשק, קובץ ההגדרות של העיצוב (צבעים וגופנים), תיקיית הלוגו, רשימת המסכים.

לא קוראת אף פעם: קבצי `.env`, מפתחות, טוקנים, סיסמאות, ובסיס הנתונים. מסך שמראה שמות, מיילים או כסף של אנשים אמיתיים לא מצולם.

יוצא מהמחשב שלך: שום דבר אוטומטי. הדבר היחיד שמגיע אלינו הוא הזיפ שאתה שולח במו ידיך, אחרי שהסתכלת בו. לפני הסיום הערכה סורקת את התיקייה ומוחקת כל דבר שנראה כמו מפתח או מייל אמיתי.

## ההבטחה שלנו

הערכה רק קוראת ומצלמת: היא לא משנה שום קובץ בפרויקט שלך, לא מתקינה בו כלום, לא עושה commit ולא שולחת שום דבר לשום מקום, וכל מה שהיא יוצרת יושב בתיקייה אחת שאתה רואה.
לצילום המסכים היא משתמשת ב-Chrome שכבר מותקן אצלך, בלי להוריד כלום.
אם יש מסכים מאחורי כניסה, אתה בוחר: לצלם אותם בעצמך, או לאשר לה פעם אחת להוריד חבילה קטנה בשם Playwright, ואז היא פותחת לך חלון ואתה מתחבר בעצמך (עדיף עם חשבון דמו). היא אף פעם לא מבקשת סיסמה ולא רואה אותה, והקובץ של ההתחברות נמחק בסוף ולא נשלח לנו.
בסוף היא מראה לך בדיקה: מצב הגיט ותוכן הקבצים ששונו, לפני ואחרי, זהים שורה בשורה. זו בדיקה טובה ולא הוכחה מוחלטת: גיט לא רואה תיקיות שהוא מתעלם מהן (כמו node_modules). לפני שהקבצים נסגרים היא מראה לך סיכום קצר של מה שהבינה, ואתה מתקן ומאשר.
